# alterna-b2-01-asti

Alterna · B2 · Анкара · день 1: **Прибытие: ночной автобус в AŞTİ** (Varış: AŞTİ'ye gece otobüsü).

Интерактивный урок по дневной теме дорожной карты Alterna (`d.b2.01`).

- `d.b2.01/` — сам гайд в формате платформы (как `d.b1.NN` в alterna-guides). Для переноса в общую архитектуру копируется эта папка целиком, рядом с остальными `d.*`.
- `kit/v1/` — копия общего движка kit, нужна только чтобы сайт работал отдельно. При переносе не копируется: на платформе он уже есть.
- `index.html` — переход на `d.b2.01/`.

Собрано из `alterna-ankara-b2/src/days/d.b2.01.json` скриптом `tools/build.mjs`.
